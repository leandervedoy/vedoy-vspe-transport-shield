Experimental transport-security core

VSPE Transport Shield

An experimental Rust transport-security core for future Vedoy applications.

Research status. This project is not independently audited and is not production-ready. It is not a VPN, an end-to-end messaging service, or a complete PQXDH / Double or Triple Ratchet implementation.

Hybrid startup

Identity-pinned X25519 and ML-KEM-1024 research handshake with signed transcripts.

Durable state

Encrypted local snapshots and persist-before-network outbox handling.

Transport boundary

encode_packet and decode_packet enforce bounded public wire data.

Packet lifecycle

Persist before network

A packet is returned to the application only after the next local state and encrypted outbox are committed. Network delivery, relay trust and acknowledgements remain outside the library.

1. Pin peer identity
2. Create encrypted packet
3. Commit local outbox
4. Send through authenticated transport
Public wire boundary

Keep private state local

Only a public encrypted SentPacket belongs on the wire. Passwords, PINs, private identities and snapshots never do.

let bytes = transport::encode_packet(&packet)?;
// send bytes using your authenticated transport
let packet = transport::decode_packet(&received_bytes)?;
let plaintext = session::receive_message(/* durable local store */, &packet)?;
Before any product launch

Release gates

  • Independent audit: protocol design, implementation and dependency review.
  • Platform security: Android Keystore and iOS Keychain adapters with retry and recovery policy.
  • Production protocol: reviewed PQXDH plus a complete ratchet implementation, key transparency and multi-device design.
  • Service boundary: authenticated relay, delivery receipts, abuse controls, monitoring and incident response.
